## Specific behavioral signals to watch for (mark every time observed)

- [ ] Clicks into evidence/source without being asked to — count: ____
- [ ] Questions or doubts a specific claim unprompted — count: ____, note which claim(s): _______________
- [ ] Reads a confidence/stage badge and correctly infers its meaning without asking — describe: _______________
- [ ] Asks "wait, does this mean X is already true?" about any claim — note which: _______________
  *(This is a direct, in-the-moment temporal-honesty failure signal — log it in the defect log
  immediately, don't wait for the interview.)*
- [ ] Skips the Evidence Room / evidence drawer entirely
- [ ] Gets stuck or backtracks — where: _______________, how long: ____
- [ ] Spontaneously compares this to another tool (ChatGPT, a deck, a consultant) — verbatim: _______________

  possible observation in this entire framework — see `README.md`'s litmus quote.)*

- [ ] Tries to click/edit/interact with something that isn't interactive — what: _______________
